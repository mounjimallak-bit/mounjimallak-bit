# Malak Mounji

Final-year engineering student in Data Science, Big Data and Artificial Intelligence at
ENSA Agadir, Morocco.

I work on anomaly detection in sensor time series: learning what normal operation looks like
from data, and measuring how far such a model can be trusted when labelled events are rare and
conditions change. The questions I want to pursue sit between applied mathematics, statistics
and machine learning: evaluation with few labelled events, uncertainty, and distribution shift.

## Selected work

- **[Photovoltaic fault detection from few labels](https://github.com/mounjimallak-bit/pfa-photovoltaique)**
  (internship, 2026). Autoencoders trained on healthy data only, compared with kNN and
  Mahalanobis baselines under a chronological split and a leave-one-incident-out evaluation,
  with exact intervals, a seasonal false-alarm analysis and a Kafka, TimescaleDB and Grafana
  streaming prototype. [Case study](https://mounjimallak-bit.github.io/Portfolio/post/pfa/)
- **[Axiora Data](https://github.com/mounjimallak-bit/Axiora-data-app)** (personal project,
  2025–2026). 48 official statistical tables for the Souss-Massa region, transcribed and
  validated automatically, and a descriptive analysis of poverty change between 2004 and 2014.
  [Case study](https://mounjimallak-bit.github.io/Portfolio/post/axiora/)
- **[Real estate rental platform](https://github.com/mounjimallak-bit/Estate-rental-web-application-Flask-Oracle)**
  (coursework). Business rules enforced in Oracle PL/SQL and tested against the database.
